# Prueba global de Farmacología

Aplicación estática para practicar desde computador o celular.

## Contenido

- 135 preguntas: 15 por cada una de las 9 clases.
- Modos Práctica y Simulación.
- Selección de clases, dificultad, cantidad y orden.
- Corrección explicada y resultados separados por clase.
- Repaso de errores y progreso guardado en el navegador.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio.
3. En la configuración del repositorio, activa GitHub Pages desde la rama principal y la carpeta raíz.
4. Abre la dirección pública que GitHub muestre cuando termine la publicación.

No necesita instalación ni base de datos. El progreso de cada estudiante queda guardado localmente en su propio navegador.

## Archivos principales

- `index.html`: interfaz.
- `styles.css`: diseño adaptable a celular.
- `app.js`: lógica de pruebas y progreso.
- `questions.js`: banco de preguntas.
- `assets/pharmacology-study.png`: visual científico.
